關於本站

這是一個非官方的資訊整理網站，與蔣萬安本人、其競選團隊、臺北市政府或任何政黨均無關聯，也未接受任何委託或資助。

整理方式

  • 內容取自臺北市政府公開資訊與主流媒體報導，每一項都附來源連結與日期。
  • 狀態分為四類：已完成（已實施或啟用）、進行中（施工或推動中）、規劃中（市府提議、爭取中，尚未定案）、連任政見（競選期間提出的未來承諾）。
  • 只描述做了什麼、提了什麼，不評價政策好壞。政策效果請參考各方評論與官方數據。

注意事項

  • 資料截至 ，之後的變動不會自動更新。
  • 媒體報導可能與官方最終數字有落差，引用前請點開原始來源確認。
  • 發現錯誤？歡迎到 GitHub repo 開 issue。
